## Quick 2-Step Setup
1. Visit the link above on Sketchfab and log in with your free account.
2. Click **Download 3D Model** $\to$ Select **Autoconverted format (glTF)** or **.glb**.
3. Rename the downloaded file to **`phoenix.glb`** and place it in this exact folder:
   ```
   e:\my-portfolio\public\models\phoenix.glb
   ```
